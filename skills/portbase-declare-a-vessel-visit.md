# Create and declare a vessel visit to the port, then read it back or cancel it in the Vessel Visit API.

API: Portbase Vessel Visit API (https://portvisit.pcs.portbase.com/api-documentation/index.html)

## Auth
Send the `Portbase-access-key-id` and `Portbase-secret-access-key` headers on every call. Portbase issues the access keys (see https://support.portbase.com/hc/en-gb/articles/29950455304594-Create-system-interface-with-Vessel-Notification).

## Steps
1. Find the vessel with `get01` (POST /refdata/findVessels).
2. Create the visit with `createVisit` (POST /declarations/createVisit) and keep the CRN.
3. Declare the visit with `declareVisit` (PUT /declarations/visit).
4. Read a version with `getVisit_1` (GET /declarations/visit/{crn}/version/{version}) and update it with `updateVisit` (POST /declarations/visit/{crn}).
5. Poll for authority responses with `_01_listenForVisitUpdates` (POST /listen); cancel with `cancelVisit` (DELETE /declarations/visit/{crn}).
