# File a bill of lading for customs (ENS/ICS2 single filing) through the Vessel Visit Consignments API.

API: Portbase Vessel Visit API (https://portvisit.pcs.portbase.com/api-documentation/index.html)

## Auth
Send the `Portbase-access-key-id` and `Portbase-secret-access-key` headers on every call. Portbase issues the access keys (see https://support.portbase.com/hc/en-gb/articles/29950455304594-Create-system-interface-with-Vessel-Notification).

## Steps
1. Send a straight B/L with `c01StraightBillOfLadingSingleFiling` (POST /consignment/straight-bl-single-filing) or a master and house B/L with `c02MasterBillOfLadingSingleFiling` (POST /consignment/master-bl-single-filing).
2. Check processing with `getConsignment` (POST /consignment/get-consignment).
3. Withdraw a filing with `c09FilingInvalidate` (POST /consignment/filing-invalidate-request).
