# Create, update and cancel a barge voyage in Hinterland Container Notification, and listen for updates.

API: Portbase Hinterland Container Notification API (https://hcn.pcs.portbase.com/api-documentation/index.html)

## Auth
Send the `Portbase-access-key-id` and `Portbase-secret-access-key` headers on every call. Portbase issues the access keys (see https://support.portbase.com/hc/en-gb/articles/29950155564562-Create-a-system-interface-API-with-Hinterland-Container-Notification-Barge-Rail-or-Road).

## Steps
1. Look up the barge with `_03_findBarges` (POST /refdata/findBarges).
2. Create the voyage with `_01_createVoyage` (POST /voyages:create).
3. Change it with `_02_updateVoyage` (POST /voyages:update) and read it back with `_06_getVoyage` (POST /voyages:get).
4. Poll for terminal responses with `_01_listen` (POST /listen).
5. Cancel with `_03_cancelVoyage` (POST /voyages:cancel).
