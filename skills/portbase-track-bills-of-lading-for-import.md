# Track bills of lading in Cargo Controller Import, then nominate an inland operator and assign a cargo director.

API: Portbase Cargo Controller Import API (https://cargo-controller.pcs.portbase.com/api/public/index.html)

## Auth
Send the `Portbase-access-key-id` and `Portbase-secret-access-key` headers on every call. Portbase issues the access keys (see https://support.portbase.com/hc/en-gb/articles/29522670809746-Create-a-system-interface-API-with-Cargo-Controller-Import).

## Steps
1. Submit the bills of lading to track with `track_1` (POST /public/track-requests).
2. List what is being tracked with `trackedBls_1` (GET /public/tracked-bls) and pick the trackRequestId.
3. Nominate the inland operator with `nominateInlandOperators_1` (PUT /public/track-requests/{trackRequestId}/inland-operator-nominations).
4. Assign a cargo director with `assignCargoDirector` (PUT /public/track-requests/{trackRequestId}/assign-cargo-director).
5. Status changes arrive by webhook (spec tag `Webhook Events`); PUT calls replace the nomination, so retrying the same body is safe.
