# Create a road visit with container handlings in Hinterland Container Notification, then update its ETA or delete it.

API: Portbase Hinterland Container Notification API (https://hcn.pcs.portbase.com/api-documentation/index.html)

## Auth
Send the `Portbase-access-key-id` and `Portbase-secret-access-key` headers on every call. Portbase issues the access keys (see https://support.portbase.com/hc/en-gb/articles/29950155564562-Create-a-system-interface-API-with-Hinterland-Container-Notification-Barge-Rail-or-Road).

## Steps
1. Find the terminal with `_08_getTerminals` (POST /refdata/getTerminals).
2. Create the road visit with `_01_createVisit_2` (POST /v2/roadvisits) and keep the visitUuid.
3. Read its state with `_04_getVisitByUuid_1` (GET /v2/roadvisits/{visitUuid}).
4. Change the ETA with `_02_updateRoadVisitEta_1` (PATCH /v2/roadvisits/{visitUuid}), or cancel with `_05_deleteRoadVisit_1` (DELETE /v2/roadvisits/{visitUuid}).
5. Use the v2 paths: the spec says version numbers denote incompatible changes and that older versions will eventually stop being supported.
