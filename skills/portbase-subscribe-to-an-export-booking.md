# Subscribe to an export booking in Cargo Controller Export and read its booking dossier.

API: Portbase Cargo Controller Export API (https://api.cargo-controller-export.pcs.portbase.com/api/public/index.html)

## Auth
Send the `Portbase-access-key-id` and `Portbase-secret-access-key` headers on every call. Portbase issues the access keys (see https://support.portbase.com/hc/en-gb/articles/34948493768466-Creating-a-system-interface-API-with-Cargo-Controller-Export).

## Steps
1. Subscribe to the booking with `subscribe` (POST /v1/bookings) and keep the returned subscriptionId.
2. Read the booking dossier with `getBySubscriptionId` (GET /v1/bookings/{subscriptionId}).
3. Fetch the JSON Web Key Set with `getJwks` (GET /public/.well-known/jwks.json) to verify signed webhook deliveries.
